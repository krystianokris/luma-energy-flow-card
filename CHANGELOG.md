# Changelog

## 0.1.0

First standalone Home Assistant release: six layouts, visual configuration and tile positions, Glass Navy/Clear Glass materials, embedded day/night/weather WebP scenes, optional solar/battery/EV/gas/heat-pump/heating, Octopus GBP readings, HA more-info events, demo mode, responsive layout and reduced motion. Read-only; no device service calls. HACS custom-repository layout. Live installation testing in HA is still pending.
