# Artwork provenance

All six used background images are local WebP files, bundled as data URLs in the release JavaScript. No stock-photo website or third-party photograph is required.

| File | Scene |
| --- | --- |
| `assets/house-day.webp` | Sunny day |
| `assets/house-cloudy.webp` | Overcast day |
| `assets/house-rain.webp` | Rainy day |
| `assets/house-stars.webp` | Starry night |
| `assets/house-night-cloudy.webp` | Overcast night |
| `assets/house-night-rain.webp` | Rainy night |

Created using the built-in OpenAI image-generation tool for the author's existing energy-flow project and reused here with the author's authorization. Variants retain the same modern house, camera angle, solar roof, car, charger and landscaping. Prompts changed weather and lighting only and excluded labels, interface overlays, logos and people. Conversion to WebP removed the need to distribute the large generated PNG files.

Prompt family: “Original photorealistic architectural smart home; contemporary charcoal flat-roof house, open garage with battery and inverter, solar panels, unbranded silver EV at left, warm windows, heat pump, driveway and landscaped garden. Preserve exact camera, crop and equipment positions. Change only weather and illumination to sunny day / overcast day / rainy day / starry night / cloudy night / rainy night. Full-bleed landscape 16:9, no text, UI, logos or people.”

The author permits redistribution of these supplied image files with this MIT-licensed card to the extent of the author's rights. No exclusive copyright protection in AI-generated artwork is claimed. Development dependencies retain their own licenses and are not bundled into runtime.
